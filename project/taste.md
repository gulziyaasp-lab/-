# Банк вкуса — читать перед каждым роликом. Применять по умолчанию.

## Главное (от автора, 2026-11-10)
− Плашки/подложки под текстом — НЕ НУЖНЫ (и не много элементов-плашек: чипы, карточки). Текст прямо по кадру.
+ Моушн-дизайн, «чтобы интересно было смотреть»: кинетическая типографика, а не статичные титры.

## Типографика
+ Референс «3 горнолыжных курорта Франции»: плотный гротеск КАПСОМ, строки стопкой, финальное/акцентное слово строчными жирным, огромная цифра слева от стопки строк.
+ Субтитры: капс, без подложки, 1–3 слова, слова влетают по буквам снизу; произносимое слово — акцентным цветом. Длинная группа автоматически уменьшается, чтобы влезть в x 110–970.

## Цвет
+ Палитра беж/хаки (референс: хаки-кнопки на бежевом). На светлом фоне: текст тёмно-хаки (50,44,28), акцент хаки (102,86,52) + лёгкий кремовый ореол (blur 6, ~60 %) для читаемости на руках/тёмных местах.

## Моушн-приёмы (reel1 v4)
+ Строки: буквы по одной снизу / «влёт» с масштаба 1.45→1 / въезд сбоку, строки чередуют стороны.
+ Рисованные штрихи хаки: подчёркивание под акцентом, обводка-круг вокруг слова, знак вопроса рисуется на стене рядом с головой.
+ Цифры — счётчик-барабан (цифры прокручиваются).
+ Камера: мягкие наезды-«пульсы» на ключевых словах (+3–6 %), склейки прикрыты зумом 1.00↔1.08, медленный дрейф внутри плана.
+ Звук: pop на каждую строку, tick-тики под счётчик, мягкий whoosh на въезд.
